# FINIS

Aplicación web para organizar finanzas personales y familiares.

## Ejecutar el proyecto

1. Instala las dependencias: `npm install`
2. Copia `.env.example` a `.env` y configura la URL de la API.
3. Inicia la aplicación: `npm run dev`

## Funcionando

Inicio de sesión, registro y panel de finanzas conectado a la API.
